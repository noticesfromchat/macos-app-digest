# imagegen-frontend-web

Generate design-reference images for the requested website or sections. Follow the
brief's content, brand and composition constraints. Use separate section images when
that improves readability or the user requests them; a whole-page image is valid when
requested and legible. Do not invent a six- or eight-image quota for an unspecified page.
Choose aspect ratio for the intended viewport. Preserve one coherent visual system
across the set and avoid repetitive compositions that obscure the content hierarchy.

## References

Read only the reference needed for the current decision.

- [Hero, section composition and hierarchy](references/composition.md)
- [Imagery, palette and materials](references/art-direction.md)
- [Optional page packs and interpretation examples](references/examples.md)
## Delivery

Complete the requested output and inspect the result. Fix material problems and verify
the affected output again; stop when it meets the brief or a concrete blocker prevents
progress. Do not impose a fixed number of confirmation or polishing rounds. State any
remaining limitations honestly. User approvals already given remain valid within scope.
