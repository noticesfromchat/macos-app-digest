# imagegen-frontend-mobile

Generate the requested mobile screen images. Infer the platform and flow from the
brief, preserving supplied product and brand decisions. Keep navigation, safe areas,
type and palette coherent across screens. A device frame is optional; the app content
must remain readable. Generate the requested screens without adding unrelated flows.
This skill's deliverable is images; continue to implementation only if the user asks.

## Delivery

Complete the requested output and inspect the result. Fix material problems and verify
the affected output again; stop when it meets the brief or a concrete blocker prevents
progress. Do not impose a fixed number of confirmation or polishing rounds. State any
remaining limitations honestly. User approvals already given remain valid within scope.
