# Cinematic interface design

Use this skill when expressive composition or motion is part of the request.
Follow the brief and established design system. Choose techniques for the content;
there is no mandatory animation library, page skeleton, font or image quota.

## Composition options

A campaign may use attention, interest, desire and action as a narrative structure.
A publication or tool should use the structure that serves reading or operating it.
Choose cinematic center, artistic asymmetry or editorial split from the content.
Size headlines for readable line length across viewports instead of a fixed line
count. Use deliberate negative space; do not hide overflow to conceal layout defects.

For a bento composition, plan spans around meaningful groups and preserve reading
and focus order. Dense grid packing is appropriate only when it does not scramble
that order. Cards, navigation pills and large section padding are options, not a
substitute for the project's component language.

## Motion options

When useful, consider scroll pinning, image scale/fade, card stacking or text reveals.
Use the existing animation stack; add GSAP only when the requested effect warrants it.
Clickable elements need clear focus and interaction states, not necessarily movement.
Keep core content visible and accessible without animation. Honor reduced motion,
pause off-screen loops and clean up listeners. Static layouts are valid.

## Assets and content

Inline heading imagery, horizontal accordions, marquees and testimonial carousels
can support a suitable brief. Keep readable text, keyboard controls and authentic
source material. Use actual subject imagery; a seeded placeholder URL is not a
verified relevant image. Preserve meaningful labels, metadata and house typography.

## Execution and verification

Select a coherent direction from the evidence. If random exploration is requested,
run an actual randomization tool and describe only its real output. Never simulate
execution evidence or claim a layout guarantee without checking it.
Build the requested result, inspect the affected viewports and interactions, then
fix material failures. Report the result and actual checks, without a compulsory
pre-flight transcript or invented performance claims.
