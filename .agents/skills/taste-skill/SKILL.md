# design-taste-frontend

Design the requested landing page, portfolio or redesign. Infer the design direction
from the brief and existing assets. Ask only when an unresolved decision would
materially change the result. Preserve the current stack, brand and factual content
unless the requested redesign changes them. Choose techniques by audience and task;
a particular library, motion effect or visual style is not required merely because
it appears in the reference catalog.

## Delivery

Complete the requested output and inspect the result. Fix material problems and verify
the affected output again; stop when it meets the brief or a concrete blocker prevents
progress. Do not impose a fixed number of confirmation or polishing rounds. State any
remaining limitations honestly. User approvals already given remain valid within scope.
