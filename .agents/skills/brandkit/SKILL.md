# brandkit

Generate the requested brand-kit images. Establish the brand's purpose, audience and
recognizable idea from the brief before composing a board. Preserve supplied logos,
colors and naming. Choose board dimensions and panel count for the requested output;
the example grids are options. Use concise copy and consistent application mockups.

## Delivery

Complete the requested output and inspect the result. Fix material problems and verify
the affected output again; stop when it meets the brief or a concrete blocker prevents
progress. Do not impose a fixed number of confirmation or polishing rounds. State any
remaining limitations honestly. User approvals already given remain valid within scope.
