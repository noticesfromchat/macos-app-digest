# image-to-code

Implement the requested website from its visual references. Start with supplied images
when available; generate new design references only when requested or when the brief
calls for developing a visual concept. A typography fix or an existing screenshot
implementation does not require new image generation.

Inspect reference layout, type, spacing, assets and responsive implications, then
implement semantic, accessible components in the existing stack. Preserve factual
copy and project constraints when an image contains invented or illegible material.
Choose image count and framing for the requested coverage. Generate or crop details
only when they resolve an actual gap; do not regenerate every section automatically.

## Delivery

Complete the requested output and inspect the result. Fix material problems and verify
the affected output again; stop when it meets the brief or a concrete blocker prevents
progress. Do not impose a fixed number of confirmation or polishing rounds. State any
remaining limitations honestly. User approvals already given remain valid within scope.
